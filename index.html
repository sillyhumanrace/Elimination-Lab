01 / KEEP EQUALITY TRUE

Every term gets multiplied.

2x + 3y = 12
6x + 9y = 36

Multiplying both sides by 3 creates an equivalent equation. It has exactly the same solutions.

6x + 3y = 12 is not equivalent. Multiplying only one term changes the relationship.

02 / MAKE A ZERO

Opposites cancel when added.

+3y + (−3y) = 0

Add equations with opposite coefficients. Subtract equations with equal coefficients. Either way, a coefficient becomes zero.

Subtraction affects the entire second equation—including its constant.

03 / KEEP BOTH CONDITIONS

One coordinate isn't the solution.

The combined equation helps you find one variable. Substitute that value into an original equation to find the other.

A single combined equation can contain extra points. Keep an original equation alongside it to preserve the full system.

04 / NOTICE SPECIAL CASES

Sometimes both variables disappear.

0 = 5 Never true → no solution
0 = 0 Always true → infinitely many solutions*

*For the valid two-variable linear equations in this lab, an identity means the original lines coincide. A contradiction means parallel, distinct lines.

Need a refresher? Signs, substitution, and the meaning of a solution

Adding signed terms

3y + (−3y) = 0y. But 3y + 3y = 6y.

Subtract the whole equation

(3x + 2y) − (x + 2y) = 2x + 0y.
16 − 8 = 8 on the right.

What counts as a solution?

An ordered pair (x, y) must make both equations true. For x + y = 7 and x − y = 1, (4, 3) works: 4 + 3 = 7 and 4 − 3 = 1.

Elimination reference

1. Multiply every term of an equation by a nonzero number, if needed.
2. Add opposite coefficients or subtract equal coefficients.
3. Solve the resulting equation.
4. Substitute into an original equation.
5. Verify the ordered pair in both original equations.

0 = nonzero means no solution; 0 = 0 means infinitely many solutions for valid equations in this lab.
